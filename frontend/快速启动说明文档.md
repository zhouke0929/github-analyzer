# GitHub 项目智能分析 - 前端快速启动说明

## 环境要求

- **Node.js**: >= 18.0.0 (推荐 20.x)
- **npm**: >= 9.0.0
- **Git Bash**: Windows 用户请使用 Git Bash 运行命令

## 快速启动

### 1. 进入前端项目目录

```bash
cd github-analyzer-frontend
```

### 2. 安装依赖

```bash
npm install
```

### 3. 配置环境变量（可选）

如需连接后端服务，在项目根目录创建 `.env.local` 文件：

```bash
# 后端 API 地址（默认 http://localhost:8000/api）
NEXT_PUBLIC_API_URL=http://localhost:8000/api
```

### 4. 启动开发服务器

```bash
npm run dev
```

启动成功后，访问 http://localhost:3000 即可看到页面。

### 5. 构建生产版本

```bash
npm run build
npm start
```

## 后端服务

前端需要配合后端 API 服务使用。后端默认地址为 `http://localhost:8000/api`。

### 后端 API 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/analyze` | 发起分析任务 |
| GET | `/api/analyze/{id}/status` | 查询分析状态 |
| GET | `/api/analyze/{id}/result` | 获取分析结果 |
| GET | `/api/health` | 健康检查 |

## 主要功能

1. **输入 GitHub URL** - 支持粘贴任意 GitHub 仓库地址
2. **实时进度显示** - 分析过程中展示当前步骤和进度
3. **项目摘要** - AI 生成的中文一句话摘要
4. **README 翻译** - 保留 Markdown 格式的中文翻译
5. **技术栈分析** - 识别编程语言、框架和工具
6. **导出报告** - 一键下载 Markdown 格式的分析报告
7. **深色/浅色模式** - 支持主题切换

## 常见问题

### Q: 页面显示"网络请求失败"
A: 请确认后端服务已启动，且 `NEXT_PUBLIC_API_URL` 配置正确。

### Q: 样式没有正确加载
A: 尝试清除 Next.js 缓存：
```bash
rm -rf .next
npm run dev
```

### Q: 端口 3000 被占用
A: 使用其他端口启动：
```bash
npm run dev -- -p 3001
```
