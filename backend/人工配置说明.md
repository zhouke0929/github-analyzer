# GitHub项目智能分析 - 人工配置说明

## 必须配置项

### 1. OpenAI兼容API配置（必填）

**用途：** 调用AI模型进行翻译、摘要生成等

**支持的API提供商：**

| 提供商 | OPENAI_BASE_URL | 说明 |
|--------|-----------------|------|
| OpenAI | `https://api.openai.com/v1` | 官方API |
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | 阿里云 |
| DeepSeek | `https://api.deepseek.com/v1` | DeepSeek |
| Moonshot | `https://api.moonshot.cn/v1` | Kimi |
| 智谱AI | `https://open.bigmodel.cn/api/paas/v4` | ChatGLM |

**配置方式：**

在 `backend/.env` 文件中：
```env
# 以DeepSeek为例
OPENAI_API_KEY=sk-xxxxxxxxxxxxxxxxxxxx
OPENAI_BASE_URL=https://api.deepseek.com/v1
OPENAI_MODEL=deepseek-chat
```

## 可选配置项

### 1. GitHub Personal Access Token（可选）

**作用：** 提高GitHub API请求频率限制

| 认证方式 | 请求限制 | 说明 |
|---------|---------|------|
| 无Token | 60次/小时 | 个人使用或测试足够 |
| 有Token | 5000次/小时 | 多用户或生产环境建议配置 |

**是否必须配置？**
- 个人使用/测试：**不需要**，60次/小时足够
- 生产环境/多用户：**建议配置**，避免频繁限流

**获取步骤：**

1. 登录GitHub，进入 **Settings** → **Developer settings** → **Personal access tokens** → **Tokens (classic)**
2. 点击 **Generate new token** → **Generate new token (classic)**
3. 填写Note（如：github-analyzer）
4. 选择权限：勾选 `public_repo`（仅分析公开仓库即可）
5. 点击 **Generate token**
6. **立即复制** token（格式：`ghp_xxxxxxxxxxxxxxxxxxxx`）

**配置方式：**

在 `backend/.env` 文件中：
```env
GITHUB_TOKEN=ghp_xxxxxxxxxxxxxxxxxxxx
```

### 2. CORS跨域配置

如果前端部署在其他地址，需要配置CORS：

```env
CORS_ORIGINS=["http://localhost:3000","http://127.0.0.1:3000","https://your-domain.com"]
```

## 常见配置问题

### Q: 提示 "GitHub API请求频率超限"

**原因：** 
- 无Token时限制60次/小时，可能被其他用户用完
- 有Token时限制5000次/小时，通常足够

**解决：** 
- 等待1小时后重试
- 或配置 `GITHUB_TOKEN` 提高限额

### Q: 提示 "AI模型调用失败"

**原因：** OpenAI兼容API配置错误

**解决：**
1. 检查 `OPENAI_API_KEY` 是否正确
2. 检查 `OPENAI_BASE_URL` 是否可访问
3. 检查 `OPENAI_MODEL` 是否为该提供商支持的模型
4. 确认API账户余额充足

### Q: 前端无法连接后端

**原因：** CORS配置问题

**解决：**
1. 确认后端服务已启动
2. 在 `.env` 中添加前端地址到 `CORS_ORIGINS`
3. 重启后端服务
