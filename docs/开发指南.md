# GitHub项目智能分析 - 开发指南

## 项目概述

本项目是一个AI驱动的Web应用，帮助中国开发者快速理解和评估GitHub项目。

**核心功能：**
- README中文翻译（保留Markdown格式）
- 项目一句话摘要
- 技术栈分析
- 技术架构分析
- Issues趋势分析
- Agent 智能问答（基于 RAG + 混合检索）

**技术亮点：**
- Agent 编排：ReAct 模式，自动选择工具回答问题
- 混合检索：精确代码搜索 + 语义向量检索
- 多模型支持：OpenAI/Claude/通义千问等

## 开发环境搭建

### 后端

```bash
# 1. 进入后端目录
cd backend

# 2. 创建虚拟环境
python -m venv venv

# 3. 激活虚拟环境
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate

# 4. 安装依赖
pip install -r requirements.txt

# 5. 配置环境变量
cp .env.example .env
# 编辑 .env 文件，填入API密钥

# 6. 启动服务
python run.py
```

后端地址：http://localhost:8000
API文档：http://localhost:8000/docs

### 前端

```bash
# 1. 进入前端目录
cd frontend

# 2. 安装依赖
npm install

# 3. 启动开发服务器
npm run dev
```

前端地址：http://localhost:3000（同时支持 http://127.0.0.1:3000）

## 已知问题和解决方案

### 1. 代理问题

**问题**：开启系统代理时，GitHub API返回401错误

**解决**：在httpx客户端中设置`trust_env=False`

```python
async with httpx.AsyncClient(trust_env=False) as client:
    response = await client.get(url, headers=headers)
```

### 2. AI模型兼容性

**问题**：部分模型对长prompt返回空字符串，或输出思考过程

**解决**：
- 使用JSON格式强制结构化输出（`response_format={"type": "json_object"}`）
- 对翻译/摘要场景使用`generate_with_system()`配合系统提示

### 3. GitHub API限流

**问题**：无Token时60次/小时限制

**解决**：
- 配置GitHub Token提升到5000次/小时
- 后续可添加缓存功能避免重复请求

### 4. Next.js 127.0.0.1 访问问题

**问题**：通过 `127.0.0.1:3000` 访问时按钮灰色不可用

**解决**：在 `next.config.ts` 中添加 `allowedDevOrigins`

```typescript
const nextConfig: NextConfig = {
  allowedDevOrigins: ["127.0.0.1"],
  // ...
}
```

### 5. 仓库更新时间不准确

**问题**：`updated_at` 字段会因 star、issue 等活动更新，不代表代码更新时间

**解决**：改用 `pushed_at` 字段（代码实际推送时间）

```python
"updated_at": data.get("pushed_at") or data.get("updated_at")
```

### 6. AI输出思考过程

**问题**：模型在翻译/摘要时输出内部推理过程

**解决**：使用 `generate_with_system()` 配合系统提示，强制只输出结果

## 常见问题

### Q: 如何切换AI模型？

修改`.env`文件中的配置：

```env
OPENAI_API_KEY=your_key
OPENAI_BASE_URL=your_base_url
OPENAI_MODEL=your_model
```

### Q: 如何查看API文档？

启动后端后访问：http://localhost:8000/docs

### Q: 数据库在哪里？

SQLite数据库在`backend/data/analyzer.db`，首次运行时自动创建。

### Q: 如何重置数据库？

删除`backend/data/analyzer.db`文件，重启服务会自动重建。
